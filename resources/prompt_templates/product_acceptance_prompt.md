# 完整产品验收

请对项目“{{PROJECT_NAME}}”执行一次完整产品验收。本次验收是独立检查，不得自动把项目标记为已完成。

## 读取范围

1. 读取 项目记录.md 作为历史索引。
2. 读取最新有效产品：{{LATEST_PRODUCT}}。
3. 读取 原始需求/ 中的全部资料。
4. 根据项目记录，只针对需要核对闭环的要求读取相关客户反馈。
5. 读取 公共工具/WORKFLOW.md 和 公共工具/validate-tool.js。
6. 不要默认读取所有历史 HTML 或所有历史截图。

## 验收范围

- 需求完整性与课堂效果
- 数学内容正确性
- 动画、交互和参数边界
- 常用分辨率下的显示与操作
- validate-tool.js 验证结果
- 多轮修改后是否存在回归问题

## 输出要求

给出“通过”或“存在问题”的明确结论。存在问题时逐项说明证据、影响和建议修正内容；不要修改 GUI 状态，不要声称客户已经满意。
