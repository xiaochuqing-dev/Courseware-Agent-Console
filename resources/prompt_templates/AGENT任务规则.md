# AGENT 任务规则

## 通用执行规则

1. 开工前先读取当前项目的《当前任务.md》和“原始需求”目录中的全部 JSON。
2. 公共制作规范与工具统一从根目录“公共工具”读取，不复制或改写公共工具原件。
3. 原始需求和客户反馈只读，制作结果写入当前项目的“产品迭代”目录。
4. 遇到需求含义不明确、素材缺失或规则冲突时，明确列出问题，不自行猜测客户意图。
5. 完成后把执行时间、产物路径、验证结果和遗留问题追加到《项目记录.md》。

## 首次制作

1. 读取当前项目“原始需求”中的 JSON，确认页面数量、文本、素材和交互要求。
2. 按“公共工具/WORKFLOW.md”执行，并以“公共工具/template.html”为制作起点。
3. 将本次完整产物放入当前项目“产品迭代”下的新目录，保留可继续修改的源文件。
4. 使用“公共工具/validate-tool.js”检查最终 HTML；验证失败时先修正再交付。
5. 同时遵循《当前任务.md》中的特殊要求；特殊要求为空时仅按本规则执行。
