# 课件制作工作流

## 输入检查

1. 读取当前项目“原始需求”目录中的全部 JSON。
2. 核对课件标题、页面数量、页面顺序、正文、素材引用和交互要求。
3. 不确定的信息列为待确认项，不凭空补写业务内容。

## 制作

1. 复制公共工具中的 template.html 到本次产品迭代目录，以副本为起点修改。
2. 每页使用一个 section.slide，页面顺序与需求一致。
3. 素材使用相对路径，保证整个迭代目录可以独立打开。
4. 保持 16:9 画布、清晰层级和适合课堂投屏的字号。

## 验证

在项目组根目录执行：

node 公共工具/validate-tool.js 项目N/产品迭代/本次产物/index.html

只有验证退出码为 0 才视为结构检查通过。最后更新当前项目的《项目记录.md》。
