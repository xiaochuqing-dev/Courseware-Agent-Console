# 阶段三实施报告

## 1. 阶段三目标

完成 GUI 完整显示修复、工作流优化模块、Prompt 与规则收口、异常处理、完整业务回归和 Windows v1.0.0 发布构建。GUI 继续只执行确定性文件规则，不调用模型，不替用户做产品判断。

## 2. GUI 完整显示修复

- 主窗口最低支持尺寸调整为 860×560；低于常规工作尺寸时依靠页面滚动保持全部操作可访问。
- 主页改为主内容纵向滚动，反馈待保存列表增加独立滚动区，保存按钮不再被大量条目推走。
- 任务操作栏使用自动换行布局；创建页在宽屏使用双列，窄屏自动切换上下排列，底部创建操作始终固定。
- 已完成项目页改用可拖动分隔布局；长根路径、归档路径和文件名使用中间或末尾省略，并用 tooltip 保留完整内容。
- Prompt 与规则编辑弹窗按可用屏幕尺寸约束，长文本区滚动，复制、保存、关闭按钮固定可见。

## 3. 支持尺寸与 DPI

自动化实际渲染验证了 980×680、1100×720、1280×800、1366×768、1440×900、1920×1080 和最大化。当前 Windows 环境设备像素比为 1.5，已完成 150% 缩放实际截图；Qt 使用设备无关布局和 PassThrough 缩放策略。125% 未在当前系统物理切换，但不存在按 100% DPI 写死的绝对定位。

## 4. 工作流优化模块

主页左侧增加独立“工作流优化”入口。页面只扫描“已完成项目”，支持项目组切换、全选、全不选、选择计数、分析 Prompt 预览/复制和优化实施 Prompt 复制，不提供自动分析、评分或智能建议。

分析 Prompt 强制公共文件只读取一次；每个项目优先读取《项目记录.md》，仅在核对具体问题时定向读取原始需求、反馈和版本。问题必须归类到 WORKFLOW.md、template.html、validate-tool.js、AGENT任务规则.md 或项目特例，第一轮只分析并等待用户确认。

优化实施 Prompt 只允许实施用户明确确认的条目，要求避免跨文件重复、保持兼容，并在修改模板或验证器后执行针对性回归。

## 5. Prompt 与规则收口

正式资源包括 AGENT任务规则.md、first_build_task.md、feedback_task.md、product_acceptance_prompt.md、workflow_optimization_prompt.md、workflow_apply_prompt.md 和 short_execute_prompt.txt。反馈任务明确使用“第N轮修改.html”，通用优先级、历史版本保护、项目记录和验证规则保持一致。

## 6. 异常处理

新增任务规则缺失恢复、公共工具完整性检查、原始需求为空、项目目录改名或删除、关键目录缺失、模板缺失、归档冲突、文件移动失败及 Windows 长路径风险提示。提示包含具体文件或路径及处理方向；确定性缺失规则可由用户确认后恢复，历史 JSON、反馈、HTML 和项目记录不会被伪造。

## 7. 完整回归结果

真实模拟创建 6 项目组，项目3完成首次制作、第一轮两图一文反馈、第二轮反馈、最新产品识别、产品验收和用户确认归档。项目1、2作为额外已完成样本，与项目3共同生成工作流优化 Prompt；Prompt 只包含所选项目且公共文件各出现一次。全链路通过。

## 8. 测试结果

- 21 项 pytest 全部通过。
- Python 模块编译与应用 smoke test 通过。
- 阶段三截图脚本通过，并生成 10 张页面、最小窗口及 DPI 截图。
- 布局脚本确认主页无横向滚动，核心控件尺寸有效。

## 9. 部署方式与产物

采用 Qt 官方 pyside6-deploy + Nuitka standalone。选择 standalone 是为了降低单文件首次解包和安全软件误报风险，并使 resources 可直接核对。构建配置为 pysidedeploy.spec，入口脚本为 scripts/build_windows.ps1。

已生成并验证：dist/CoursewareAgentConsole.dist/CoursewareAgentConsole.exe。exe 位于中文路径时可启动并执行 smoke test；资源、Prompt、公共工具、样式和图标均随包存在。目录共 67 个文件，约 70.07 MB，exe 约 7.36 MB。

## 10. 已知限制

- 最低 860×560 下需要滚动访问反馈区域，不承诺所有内容同时出现在首屏。
- 当前环境实际 DPI 为 150%，未物理切换到 125%。
- standalone 目录必须整体分发，不能只复制 exe。
- 待保存反馈仍只存在当前运行内存，关闭前需要保存。

## 11. v1.0.0 功能总览

当前版本覆盖项目组创建、动态项目、JSON 映射、公共工具、规则编辑、首次制作、多轮反馈、任务生成、最新产品识别、产品验收、手动归档、已完成项目查看、工作流复盘和优化实施入口。

后续不建议继续凭想象增加模型 API、数据库、账号、云同步或复杂 Dashboard。应进入真实使用驱动迭代，只修复可复现问题和高频流程阻力。
